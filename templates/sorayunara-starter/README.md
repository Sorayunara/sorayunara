# 🌌 Sorayunara Starter Project Template (`.sora`)

Official starter template for building high-performance, memory-safe applications in the **Sorayunara** programming language.

## 🚀 Quick Start

### 1. Clone & Setup
```bash
git clone https://github.com/Sorayunara/sorayunara-starter-template.git my-app
cd my-app
```

### 2. Run Application
```bash
sorayunara run src/main.sora
```

### 3. Build Native Executable
```bash
sorayunara build src/main.sora -o my-app.exe
```

### 4. Run Test Suite
```bash
sorayunara test
```

## 📂 Project Structure
```
my-app/
├── sorayunara.toml    # Project configuration manifest
├── src/
│   ├── main.sora      # Application entrypoint
│   └── lib.sora       # Library logic
└── tests/
    └── test_main.sora # Unit & integration tests
```
