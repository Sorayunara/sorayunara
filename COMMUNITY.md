# 🌌 Welcome to the Sorayunara Community!

We are building the future of programming languages together: **Python Simplicity + Rust Safety + Zero-Boilerplate Systems Performance**. 

Whether you are a systems programmer, web developer, compiler enthusiast, or beginner writing your first open source contribution, **you are welcome here!**

---

## 🗺️ How to Get Involved

### 1. 🐣 First-Time Contributors
Looking for an easy place to start?
- Browse **[`good first issue`](https://github.com/Sorayunara/sorayunara/issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22)** for bite-sized tasks.
- Help translate documentation into your native language in `docs/` or `README.<lang>.md`.
- Add algorithms or data structures to `examples/` or `std/collections/`.

### 2. ⚙️ Compiler & Systems Engineers
- Improve the **Hindley-Milner type inference** in `compiler/typeck/`.
- Enhance the **flow-sensitive borrow checker** in `compiler/borrowck/`.
- Add backend optimizations (LLVM, C99, WebAssembly) in `compiler/codegen/`.

### 3. 📦 Standard Library Builders
- Expand the 37 standard library modules in `std/` (networking, cryptography, linear algebra, HTTP, databases).
- Propose new standard library APIs using the [Stdlib Proposal Template](.github/ISSUE_TEMPLATE/stdlib_proposal.yml).

### 4. 🛠️ Tooling & IDE Developers
- Improve the **VS Code Extension** in `editors/vscode/`.
- Build plugins for **Vim, Neovim, Emacs, or JetBrains**.
- Enhance the Language Server Protocol (`lsp`) implementation.

Every contributor who submits a merged Pull Request:
1. Is invited to the `@Sorayunara/contributors` organization team.
2. Is listed in the official repository README Hall of Fame.
3. Receives public credit in official release notes.
