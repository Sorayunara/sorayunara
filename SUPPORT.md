# 🤝 Getting Support for Sorayunara

Need help with Sorayunara? We are here to support you!

---

## 📌 Where to Get Help

### 1. ❓ Questions & Help
If you have questions about writing `.sora` code or syntax:
- Ask in **[GitHub Discussions (Q&A)](https://github.com/Sorayunara/sorayunara/discussions/categories/q-a)**.
- Read the official **[Language Specification](SPECIFICATION.md)** and **[Language Reference](docs/LANGUAGE_REFERENCE.md)**.
- Check the **[Tutorials](docs/tutorials/getting_started.md)**.

### 2. 🐛 Reporting Bugs
Found a compiler error, parser panic, or unexpected behavior?
- Check existing issues to see if it has already been reported.
- If not, open a new issue using our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml)**.
- Provide a minimal reproducible `.sora` code snippet.

### 3. 💡 Feature Requests & Language Design
Have an idea for a new language feature or syntax ergonomics?
- Open an **[RFC Proposal](.github/ISSUE_TEMPLATE/rfc_proposal.yml)** to initiate discussion with the maintainers.

### 4. 🔒 Security Vulnerabilities
If you discover a security vulnerability in the compiler or runtime:
- Please follow our responsible disclosure policy in **[SECURITY.md](SECURITY.md)**.
