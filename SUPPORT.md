# Sorayunara Support & Communication Channels

Welcome to the Sorayunara support directory. Please use the appropriate channel for your request:

---

## Channels Directory

| Type | Destination | Notes |
| :--- | :--- | :--- |
| **Compiler Bugs & Miscompilations** | [GitHub Issues](https://github.com/Sorayunara/sorayunara/issues) | Use the `Compiler Bug` template with minimal repro. |
| **Language Feature Proposals** | [RFC Proposals](https://github.com/Sorayunara/sorayunara/tree/main/rfcs) | Submit a proposal in `rfcs/`. |
| **General Questions & Q&A** | [GitHub Discussions](https://github.com/Sorayunara/sorayunara/discussions) | Ask community questions. |
| **Security Vulnerabilities** | [Security Policy](https://github.com/Sorayunara/sorayunara/blob/main/SECURITY.md) | Use private vulnerability disclosure. |
