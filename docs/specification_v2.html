1. Executive Summary & Design Axioms

Sorayunara (.sora) is an ultra-ergonomic, memory-safe, and high-performance programming language designed to unite the developer ergonomics of modern scripting languages with the zero-cost abstractions, static ownership, and bare-metal performance of modern systems languages.

Core Motto: "Python Simplicity + Rust Safety + Functional Pipeline + Actor Concurrency"

Core Tenets

  • Grammar Compression & Zero Boilerplate: Concise, colon-free declarations (name := "Lutfi"), fat-arrow functions (fn add(a, b) => a + b), and single-line expressions.
  • Memory Safety Without Mandatory GC: Flow-sensitive borrow checking tracks resource lifecycles at compile time, eliminating data races, double frees, and memory leaks.
  • Lock-Free Concurrency: Lightweight actor coroutines (spawn) and message channels (channel<T>) eliminate multithreading locking complexity.
  • Multi-Target Codegen Architecture: Emits direct native machine code via LLVM IR (.ll), ANSI C (.c) for microcontrollers, and WebAssembly (.wasm) for cloud edge runtimes.

2. Formal EBNF Grammar (Conflict-Free)

The Sorayunara grammar is formally specified below in Extended Backus-Naur Form (EBNF). It is deterministic, unambiguous, and compatible with LALR(1) and PEG parsers. 

(* Sorayunara Formal Grammar v2.0 *)
program         = { declaration } ;

declaration     = variable_decl
                | function_decl
                | struct_decl
                | enum_decl
                | trait_decl
                | impl_block
                | actor_decl
                | module_decl
                | import_decl ;

variable_decl   = ( identifier ":=" expression )
                | ( [ "mut" | "const" ] identifier [ ":" type ] "=" expression ) ;

function_decl   = [ "async" ] [ "pub" ] "fn" identifier [ generic_params ]
                  "(" [ parameter_list ] ")" [ "->" type ]
                  ( "=>" expression | block ) ;

block           = "{" { statement } [ expression ] "}" ;

statement       = variable_decl
                | assignment
                | return_stmt
                | defer_stmt
                | guard_stmt
                | expression ;

if_expr         = "if" expression ( "=>" expression | block )
                  [ "else" ( "=>" expression | block | if_expr ) ] ;

for_expr        = "for" pattern "in" expression ( "=>" expression | block ) ;
each_expr       = "each" identifier "in" expression "=>" expression ;
while_expr      = "while" expression ( "=>" expression | block ) ;
loop_expr       = "loop" block ;

match_expr      = "match" expression "{" { match_arm } "}" ;
match_arm       = pattern "=>" ( expression | block ) [ "," ] ;

expression      = pipe_expr ;
pipe_expr       = binary_expr { "|>" binary_expr } ;
binary_expr     = unary_expr { binary_op unary_expr } ;
unary_expr      = [ "-" | "!" | "*" | "&" | "mutref" ] postfix_expr ;
postfix_expr    = primary_expr { call_suffix | member_suffix | safe_suffix | try_suffix | index_suffix } ;

call_suffix     = "(" [ argument_list ] ")" ;
member_suffix   = "." identifier ;
safe_suffix     = "?." identifier | "??" expression ;
try_suffix      = "?" ;
index_suffix    = "[" expression "]" ;

primary_expr    = literal
                | identifier
                | "(" expression ")"
                | array_literal
                | map_literal
                | struct_init
                | if_expr
                | match_expr
                | lambda_expr ;

lambda_expr     = ( identifier | "(" [ parameter_list ] ")" ) "=>" ( expression | block ) ;

4.5 Pipeline Operator & Functional Operations (|>)

Sorayunara features a first-class pipe forwarding operator |> that passes preceding values as the first argument to the downstream transformation: 

// Clean, highly readable data transformation pipeline
data := users
    |> filter(u => u.age >= 18)
    |> map(u => u.name)
    |> sort()
    |> take(10)

4.7 Concurrency & Actor Model

// Actor declaration with message handling
actor WorkerPool {
    mut jobs := 0

    on process(task: TaskMessage) {
        jobs += 1
        execute_task(task)
    }

    on get_count -> Int {
        reply jobs
    }
}

// Spawning and sending messages
pool := spawn WorkerPool()

6. Conflict-Free Grammar Verification

The Sorayunara 2.0 grammar guarantees zero shift/reduce and reduce/reduce conflicts through the following architectural constraints:

  1. Arrow Disambiguation: => is reserved exclusively for expression functions, lambda parameters, match arms, and single-line control branches. It never conflicts with relational >= or equality ==.
  2. Declaration Disambiguation: := definitively identifies short local variable bindings, eliminating lookahead ambiguity with standard assignment =.
  3. Pipeline Precedence: The |> operator binds looser than standard binary arithmetic (+, *) but tighter than assignment (=, :=).
  4. Safe Access Precedence: ?. and ?? bind tightly to primary and postfix expressions, guaranteeing deterministic unwrap chains without paren ambiguity.
